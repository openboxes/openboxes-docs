# Adding a New Language

If the language you're trying to translate is not yet in OpenBoxes or Crowdin, here's how to get it added.

## Requesting a new language

Get in contact with us by posting to the [OpenBoxes Slack](http://slack-signup.openboxes.com/), [adding a post to our community forums](https://community.openboxes.com/), or by [creating a new GitHub Issue](https://github.com/openboxes/openboxes/issues). Let us know the language that you'd like to translate and we'll get you set up as quickly as possible.

Once the language has been added, you can start translating — see [Translate OpenBoxes](./).

{% hint style="info" %}
Are you a project administrator adding the language yourself? See [Administer Crowdin](/maintainers/administer-crowdin).
{% endhint %}
