# Find Something To Work On

We have plenty of [open issues on our GitHub](https://github.com/openboxes/openboxes/issues?q=is%3Aissue%20state%3Aopen%20label%3A%22status%3A%20ready%20for%20work%22) that are ready to be worked on.

If you're new to the project and don't know where to start, we encourage you to take a look at one of our [beginner friendly tasks](https://github.com/openboxes/openboxes/issues?q=is%3Aissue%20state%3Aopen%20label%3A%22flag%3A%20beginner%20friendly%22). These are chosen to be self-contained and to not require deep knowledge of the codebase.

Of course, you're welcome to [open a new issue](https://github.com/openboxes/openboxes/issues/new) if you have a new feature or bug that you want to work on that isn't already documented. If you're proposing a larger feature, [start a discussion](https://github.com/openboxes/openboxes/discussions/categories/ideas) first so we can agree on the approach before you write code — see [Suggest a Feature](../contribute-without-code/suggest-a-feature.md).

{% hint style="info" %}
Not sure which issue suits you? [Ask on Slack](http://slack-signup.openboxes.com/) and we'll help you pick one.
{% endhint %}

Once you've chosen something, comment on the issue to let us know you're picking it up, so two people don't duplicate the same work.
