# For Maintainers

This section covers tasks that need write access to the project's repositories and tooling. If you're contributing code, translations or bug reports, you want the [Contribute](/) section instead.

* [**Cut a Release**](cut-a-release.md) — the full release procedure, from cutting the branch through to announcing it
* [**Publish a Docker Image**](publish-a-docker-image.md) — how release images are published, and how to build one by hand
* [**Administer Crowdin**](administer-crowdin.md) — adding a target language and making it selectable in OpenBoxes

These procedures assume you're familiar with how our branches work — see [Repositories and Branches](/how-openboxes-works/repositories-and-branches) in the Contribute section.
